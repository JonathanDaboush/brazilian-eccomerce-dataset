# Frontend

The frontend is a Vite + React dashboard for the replay-backed ecommerce demo.

## Commands

```bash
npm install
npm run dev
npm run build
```

## Environment

Set `VITE_API_BASE_URL` if the backend is not running on `http://localhost:8000`.

## What the UI shows

- live KPI cards
- replay controls
- processing health
- recent activity
- recent orders
- top categories
- saved ML models and sample predictions
